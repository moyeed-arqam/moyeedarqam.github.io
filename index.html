What I measure on every site.

Google’s Core Web Vitals show how fast a page feels. These are Google’s “good” targets at the 75th percentile: LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1[reference:17].

2.5 s

LCP

Largest Contentful Paint: how quickly the main content appears.

200 ms

INP

Interaction to Next Paint: how fast the page reacts to taps and clicks.

0.1

CLS

Cumulative Layout Shift: how much the page jumps while loading.

I never promise a specific score. I promise a backup first, a careful fix, and a documented before-and-after.
